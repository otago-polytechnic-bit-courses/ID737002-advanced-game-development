## Assessment Overview

In this assessment you will form a group of three to design and develop a game using a game engine of your choice. Marks are allocated for technical and professional proficiency, code quality, and documentation. You will also produce an individual game analysis report. This assessment continues directly from the Assignment assessment. You will extend the same codebase, team, and repository by implementing new features.

## Assessment Requirements - Coding

### Technical and Professional Proficiency - Learning Outcome 1 (45%)

> **Note:** Each individual must implement two new features that extend the game built during the Assignment. These features must not have been present in the Assignment submission.

#### Group

- The game must open in the chosen game engine without code or file structure modification.
- Demo the game on itch.io.

#### Individual

- Contribute two new game mechanics to the game, as evidenced by Git commits and lines of code.
- For each feature merged into the main branch:
  - Conduct a code review of another team member's code.
  - Record this activity in the GitHub issue associated with the feature.
- Communicate with team members via Microsoft Teams (or an approved alternative). Include screenshots of communication in the repository.

---

### Code Quality and Best Practices - Learning Outcome 1 (15%)

- Appropriate naming of files, variables, methods, and classes.
- Idiomatic use of the chosen programming language and game engine.
- Efficient algorithmic approach.
- Sufficient modularity in line with SOLID principles and appropriate design patterns.
- Each file includes a header comment explaining its purpose and author.
- Consistently formatted code throughout.
- No dead or unused code.

## Assessment Requirements - Written

### Documentation - Learning Outcome 1 (15%)

#### Individual - Technical Reflection

Select two game mechanics you implemented. For each, address the following in a Microsoft Word document:

- What did you implement?
- What did you research during implementation? Provide links to the resources used.
- What did you try? What worked, and what did not?
- What did you learn?
- How can you apply what you learned to future games?

Additionally, reflect on: what did you find most professionally challenging, and how did you overcome it?

#### All Written Work

- Correct spelling and grammar throughout.
- References and in-line citations formatted using APA 7th edition.

---

### Game Analysis Report - Learning Outcome 1 (15%)

Choose a game of your choice and write a game analysis report in a Microsoft Word document. Word guideline: 2,000 words.

#### Basic Story

Briefly describe the narrative premise or setting of the game.

#### Number of Players

- Is it single-player or multiplayer?
- If multiplayer, how many players can participate?
- Is the game real-time or turn-based?
- Are there different modes based on the number of players?

#### Rules and Goals

- What are the basic rules?
- Is there a win state, end state, or is it endless?
- What are the goals of the game? Are there multiple goals?
- Can players set their own goals?

#### Gameplay

- What is the genre?
- What are the core game mechanics?
- Describe the player experience across: satisfaction, learning, efficiency, immersion, motivation, emotion, and socialisation.
- Are there difficulty levels? Do they increase as the player progresses?
- Is the game easy to pick up and play?

#### Ethics and Morals

- Does the game present ethical or moral decisions (e.g., choosing to be a hero or villain)?
- Are any decisions connected to real-world ethics or morality?

#### Design Reflection

Reflect on two or three design decisions in the game that you found interesting or effective. Consider how those decisions might influence your own game development work.
